02 · stack locale

Prima di premere Avvia

L’app desktop si aspetta lo stesso stack del progetto xxxx. Carte rapide per chi scarica dal sito senza server già pronto.

⬡

Node.js 20+

Runtime per API, build Vite e il launcher stesso.

  • npm 10+ consigliato
  • npm install in root
◈

WSL + PostgreSQL

L’app avvia Postgres su porta 5432 via WSL (config stack esistente, PG 18).

  • WSL2 installato e funzionante
  • DATABASE_URL in .env
  • Migrate: npm run db:migrate
◎

Redis

Porta 6379 — avviato in WSL se non già in ascolto.

  • REDIS_URL in .env
⇄

cloudflared

Tunnel veloce verso il mondo. Cerca in Program Files o PATH.

  • Quick tunnel trycloudflare.com
  • Senza token per la modalità desktop
🔐

File .env

Copia da .env.example — mai committare secret.

  • SESSION_SECRET lungo e casuale
  • Password DB robusta
◇

Pannello web (utenti)

Chi riceve il link tunnel apre il sito xxxx nel browser — non confonderlo con l’app desktop admin.

  • Login con codici accesso (max 3 nomi)
  • Admin: codice adil (fiducia)
