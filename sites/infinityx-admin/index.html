02 · local stack

Before you press Start

The desktop app expects the same xxxx stack. Quick cards for anyone downloading from this site with no server yet.

⬡

Node.js 20+

Runtime for the API, Vite build, and the launcher itself.

  • npm 10+ recommended
  • npm install at repo root
◈

WSL + PostgreSQL

The app starts Postgres on port 5432 via WSL (existing stack, PG 18).

  • WSL2 installed and working
  • DATABASE_URL in .env
  • Migrate: npm run db:migrate
◎

Redis

Port 6379 — started in WSL if nothing is listening yet.

  • REDIS_URL in .env
⇄

cloudflared

Fast tunnel to the world. Look in Program Files or PATH.

  • Quick tunnel trycloudflare.com
  • No token required in desktop mode
🔐

.env file

Copy from .env.example — never commit secrets.

  • Long random SESSION_SECRET
  • Strong database password
◇

Web panel (users)

People who get the tunnel link open xxxx in a browser — not the desktop admin app.

  • Login with access codes (max 3 names)
  • Admin: code adil (trusted devices only)
