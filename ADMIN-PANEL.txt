xxxx Admin Panel — created by Infinity X
========================================

1. Unzip the folder.
2. Double-click  xxxx Admin.bat
3. Click  Start server  (first time: automatic setup, wait a few minutes)
4. Click  Copy link  and send it to the admin.

The admin logs in, adds guest names + secret codes in Access, and grants permissions.
Guests open the same link on their phone — live cam and device info work from Admin.

Needs on this PC: Node 20+, WSL with Postgres (5432) and Redis (6379), cloudflared.

Hub: https://infinity-x202.github.io/xxxx-messenger/
